# Антошка — запуск portable версии (Windows)

Эта инструкция для папки `dist/AntoshkaApp` после сборки PyInstaller (one-folder).
Для one-file сборки см. раздел ниже.

**Быстрый старт**
1. Скопируйте папку `dist/AntoshkaApp` на другой ПК.
2. Запустите `AntoshkaApp.exe`.
3. При первом запуске приложение создаст папки настроек и логов в `%LOCALAPPDATA%\\Antoshka`.

**Где лежат данные**
- Настройки: `%LOCALAPPDATA%\\Antoshka\\config\\settings.json`
- Логи: `%LOCALAPPDATA%\\Antoshka\\logs\\app.log`

**Что проверить после запуска**
1. Открывается окно чата.
2. Команда `помощь` показывает секции.
3. Таймер на 5 секунд срабатывает и показывает кнопки управления.
4. Уведомления: появляется системное уведомление и/или in-app.
5. В Settings доступны язык, микрофон, звук.

**Если что-то не работает**
- **Нет микрофона**: проверьте разрешения Windows и выбранное устройство в Settings.
- **Нет уведомлений**: включите уведомления для приложения в настройках Windows.
- **ИИ недоступен**: задайте ключ в `.env` или выключите ИИ в Settings.
- **Нет модели распознавания**: проверьте, что папка `models/` присутствует рядом с exe.
- **Нет звука**: проверьте системную громкость и выбранный сигнал в Settings.

**One-file режим**
1. Соберите `pyinstaller Antoshka_onefile.spec`.
2. Получите `dist/AntoshkaApp.exe`.
3. При первом запуске будет заметная пауза (распаковка).
4. Папки настроек и логов создаются в `%LOCALAPPDATA%\\Antoshka`.
