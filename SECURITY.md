# Security Policy

## Supported Versions

Current supported line:

- `0.4.x-alpha`

Older alpha builds are not guaranteed to receive fixes.

## Reporting a Vulnerability

Please do not open public issues for security-sensitive problems.

Report privately with:

1. Short summary of the issue
2. Steps to reproduce
3. Affected version/commit
4. Potential impact
5. Any logs or screenshots

Temporary contact channel for this project:

- GitHub private message to repository owner (`Alex-gs-q`)

Response target:

- Initial acknowledgment: within 72 hours
- Triage/update: within 7 days

## Scope Notes

- API keys must be provided via environment variables (`OPENAI_API_KEY`).
- Do not embed secrets into source code, specs, or release archives.
